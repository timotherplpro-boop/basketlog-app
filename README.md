# Basketlog

**Free win probabilities and projected scores for every NBA and EuroLeague game.**

Website: https://basketlog-app.com · English: https://basketlog-app.com/en · Español: https://basketlog-app.com/es

Basketlog publishes a win probability and a projected score for every NBA and EuroLeague game, every day. Each game page explains the forecast with recent form, team stats, injuries and fatigue.

## How it works
- The method: https://basketlog-app.com/en/methode
- Every forecast is saved before tip-off, then compared with the final score on a public track record: https://basketlog-app.com/en/app/bilan
- Tonight's games: https://basketlog-app.com/en/app/matchs
